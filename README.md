# 基金时光机 V7.5 投资成长训练平台

一个纯前端基金投资行为训练工具，通过模拟市场、投资日志和自动复盘帮助用户训练风险意识与决策纪律。

## V7.5 投资成长体验

- 产品定位从金融工作台调整为投资成长训练平台，围绕“观察、计划、决策、复盘”重新组织页面
- 首页：每日市场挑战、投资等级、训练进度、成长反馈和四步成长路径
- 市场训练：按观察市场、写下计划、做出决定、查看反馈组织完整训练情境
- 基金卡片：以投资方向、风险强度、学习提示和适合人群帮助用户理解基金
- 投资日志：改为成长时间线，集中展示理由、情绪、计划和后续结果
- 成长系统：根据基金选择、买入前计划、训练记录和复盘次数计算 XP、等级与成就
- 导航：保留六个主要成长入口，其余原有功能收纳到“更多训练”
- 基金数据库、模拟交易、投资日志、复盘中心及 V7 前全部业务功能保持不变

## V7 UI/UX

- 首页工作台：展示基金数量、训练进度、模拟资产和决策记录
- 导航重构：主要功能统一进入顶部导航，移动端自动切换为底部横向导航
- 基金页面：搜索筛选区、基金卡片与详情面板形成清晰的双栏结构
- 市场训练：突出当前基金、市场事件、模拟资产、结果反馈和决策问答
- 投资日志：增加操作入口和更清晰的响应式数据表格
- 视觉系统：采用克制的绿色金融配色、留白、浅边框和低阴影卡片
- 核心数据逻辑、基金数据库、模拟交易、日志和复盘逻辑保持 V6.3 不变

## V6.3 功能

- 初始化基金数据库：内置 30 只真实基金基础资料，宽基指数、行业主题、海外基金、债券基金和货币基金各 6 只
- 基金数据库：使用 IndexedDB 保存大量基金，初始化数据只补充缺失代码，不覆盖用户自行导入的记录
- 批量导入：支持 JSON 与 CSV，相同基金代码自动更新
- 基金资料：基金代码、名称、公司、类型、分类标签、投资方向、风险等级和成立日期
- 基金查找：按代码、名称、公司、方向或标签搜索，并按主分类、类型、投资方向和风险筛选
- 基金详情：展示基金名称、类型、风险、投资方向、投资特点、适合人群和净值数据接入状态
- 基金选择：按照“基金列表 → 基金详情 → 选择买入”完成交易前选择
- 买入前投资问答：保存买入理由、预计持有时间和下跌20%的处理方式
- 新手学院：基金基础、基金分类、风险收益、定投、投资准备和第一次模拟练习
- 市场训练：每日事件、买入/卖出/持有决策和第二日结果反馈
- 投资日志：记录基金、日期、操作、金额、理由、情绪和后续收益变化，并使用 localStorage 保存
- 复盘中心：分析交易次数、买卖习惯、情绪倾向、常见错误和基金类型亏损
- 策略实验室：比较定投、下跌加仓和长期持有的基础模拟结果
- 保留 V5 的亏损复盘、AI 投资教练、训练挑战和投资规则

## 使用方式

直接打开 `index.html` 即可使用，无需后端或安装依赖。

在线版本：<https://moira1122.github.io/fund-time-machine/>

## 数据说明

基金数据库保存在当前浏览器的 IndexedDB 中；训练日志继续保存在 localStorage 中。清理浏览器网站数据或更换浏览器后，这些数据不会自动同步。

导入模板位于 `data/fund-import-template.csv`。JSON 可以是基金数组，也可以使用 `{ "funds": [] }` 包装。基金代码和基金名称为必填项，多个分类标签在 CSV 中使用 `|` 分隔，成立日期使用 `YYYY-MM-DD`。投资方向、投资特点和适合人群可以导入；未提供时系统会根据分类与风险自动生成。

每条基金记录都预留 `nav` 对象，包含最新净值、净值日期、历史数据来源、接口地址和最后同步时间，方便未来接入真实历史净值。

每次买入会将三项投资问答写入日志，并输出持有期限、亏损应对、决策情绪、市场事件、基金分类和投资方向等复盘字段。

基金代码、名称、公司等基础资料整理自基金管理人官网、基金产品资料概要和公开定期报告。风险等级用于训练分类；不同销售机构的实时评级可能不同。
