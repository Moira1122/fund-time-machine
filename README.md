# 基金时光机 V8 用户成长系统

一个纯前端基金投资行为训练工具，通过模拟市场、投资日志和自动复盘帮助用户训练风险意识与决策纪律。

## V8.7 发布前校准

- 真实基金只显示资料中确实存在的份额类别，不再为真实基金自动生成 A/C 份额或虚构费率
- 训练基金继续提供 A/C 费用教学；新手学院新增持有时间与费用的互动比较，并强调字母不是收益等级
- 真实基金名称与模拟涨跌明确分开标注，避免把离线训练行情误认为真实历史净值
- 最后一个交易日可直接结束本轮并进入完整训练报告，修复训练流程断点
- 首页“投资能力评分”改为“训练纪律分”，只衡量记录、计划、规则执行和复盘完成度
- 策略实验室明确当前只比较 8 个模拟交易日，“长期持有”改为“一次投入后持有”
- 用户导入资料与投资日志统一按纯文本展示，CSV 导出增加公式注入保护
- 提高手机端辅助文字和表单字号，保持原有玻璃拟态与低饱和视觉系统

## V8.6 基金份额与费用训练

- 基金池新增 A、C、B、D 等份额类别说明，明确字母不代表收益或风险等级
- 每张基金卡展示 A 类申购费和 C 类销售服务费的离线教学示例
- 买入时可选择 A/C 份额，并结合买入金额与预计持有时间比较费用
- 费用估算拆分为申购费、销售服务费和赎回费，短期赎回会单独提示
- 投资日志和导出文件会保留份额类别与费用学习估算
- B、D 等份额不做统一推荐，因为其含义需要以具体基金文件为准

## V8.5 次日结果揭晓

- 点击“进入下一交易日”后，先以 3—2—1 倒计时制造开盘前的等待感
- 揭晓当日账户盈亏、收益率和最新总资产，并遵循 A 股“涨红跌绿”的颜色习惯
- 对持有基金逐只展示当日涨跌、金额变化和最新市值，持仓较多时可单独滚动查看
- 结果后保留一句决策复盘：盈利不自动证明决定正确，亏损也不自动证明决定错误
- 支持跳过倒计时；弹窗关闭后继续当天的多基金操作和日志记录

## V8.4 免费功能补全版

- 基金池现包含 15 个训练标的和 30 只离线真实基金基础资料，并支持搜索、分类和 JSON/CSV 本地导入
- 新增 4 个 8 日离线市场剧本：高位震荡、漫长调整、突发冲击与热门赛道
- 市场训练支持同一天连续买入或卖出多只基金，持仓跨日保留，并逐只展示金额、当日涨跌和累计收益
- 买入前记录预计持有期、下跌 20% 时的应对方式，并实际检查单次投入与单只基金仓位规则
- 策略实验室可比较定期定额、下跌加仓和长期持有的收益、回撤、操作次数与实际投入
- 复盘中心新增动态洞察、训练成就、挑战进度、历史轮次报告和不联网的本地规则教练
- 修正固定复盘文案，报告现在会根据真实日志、规则执行和复盘完成率变化
- 所有记录继续保存在当前浏览器，不需要账号、后端、付费接口或大模型 API

## 数据说明

内置基金基础资料位于 `data/funds.json`；用户自行导入的基金、训练日志、持仓、规则和复盘保存在当前浏览器的 localStorage 中。清理浏览器网站数据或更换浏览器后，这些数据不会自动同步。

导入模板位于 `data/fund-import-template.csv`。JSON 可以是基金数组，也可以使用 `{ "funds": [] }` 包装。基金代码和基金名称为必填项，多个分类标签在 CSV 中使用 `|` 分隔，成立日期使用 `YYYY-MM-DD`。投资方向、投资特点和适合人群可以导入；未提供时系统会根据分类与风险自动生成。

每条基金记录都预留 `nav` 对象，包含最新净值、净值日期、历史数据来源、接口地址和最后同步时间，方便未来接入真实历史净值。

每次买入会将三项投资问答写入日志，并输出持有期限、亏损应对、决策情绪、市场事件、基金分类和投资方向等复盘字段。

基金代码、名称、公司等基础资料整理自基金管理人官网、基金产品资料概要和公开定期报告。风险等级用于训练分类；不同销售机构的实时评级可能不同。
